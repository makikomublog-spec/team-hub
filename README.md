# チーム管理ツール（team-hub）

チームの **タスク・カレンダー・議事録・資料・メンバー** を1つにまとめるWebツールです。
オンライン会議を **録音して自動で文字起こし** し、そのまま議事録にできます。

- あなた専用のサイトとして、**あなたのCloudflareアカウント** に作られます（作った人のデータは、配布した人からは見えません）
- Cloudflareの **無料枠** で動きます
- パソコンでもスマホでも、ブラウザから使えます（録音はパソコンのGoogle Chromeで）

---

## できること

| 画面 | できること |
|---|---|
| まとめ | 目的・方向性、優先タスク、次の節目、最新の決定事項、検討中のこと |
| カレンダー | タスクの期間をバーで表示。ドラッグで日程を変更 |
| タスク | 担当・期限・優先度・完了条件。変更はすぐ保存、履歴も残る |
| 議事録 | 🎙 録音して文字起こし → AIで議事録に整理 → PDFで保存 |
| 情報源 | 要項・資料（PDFなど）を保管。AIで締切やタスクに整理、前の版と比較 |
| メンバー | 自己紹介カード。参加の依頼を許可してメンバーを追加 |

## はじめかた

> **いまは試験公開中です。** 本物のCloudflareでの設置と文字起こしは、これから協力者の方に確認していただきます。

パソコンのGoogle Chromeで、次のページを開いて、案内どおりに進めるだけです。パソコンに何かを入れることはありません。GitHubのアカウントも要りません。

https://team-hub-setup.makikomublog.workers.dev

やることは3つです。

1. Cloudflare（ツールを置く場所）に無料登録する
2. 「鍵」を作って、ページに貼り付ける
3. サイトのドメインを指定して、「作る」を押す

作るのはチームで1人だけです。できたら完成の画面の緑のボタンから開いて、「はじめての設定」を済ませます。このボタンから開いた人だけが管理者になれます。

「はじめての設定」では、ご自身のGoogleアカウントで、このツール専用のログインの入口を作ります（Google Cloudでの作業です。無料で、最初に1回だけです）。画面が1手順ずつ案内します。そのあと、ほかの方に入ってもらいます。

### メンバーに入ってもらう
1. 「メンバー」の上の **「URLをコピー」** を押して、ツールのURLをメンバーに送ります。
2. メンバーがURLを開いてGoogleのボタンを押すと、「許可を待っています」と出ます。
3. 管理者の画面の上に「参加の依頼 1件」と出ます。「メンバー」で **「許可」** か **「断る」** を押します（メールでの通知はありません。ボタンを押したら、ひと声もらってください）。
4. 許可された人は、ページを開き直してGoogleのボタンをもう一度押すと入れます。

先に名簿へ足してある人は、依頼の欄で「名簿のどの人か」を選ぶと結びつけられます。

断った人を入れ直すときは、その人のカードの **「✉️ 招待リンク」** を使います（7日間・1回だけ使えます。**本人だけに** 送ってください）。

### 新しい版にする
設置ページを、同じアカウントの鍵ではじめから進めてください。ツールを消す必要はなく、データもそのまま残ります。

## よくある質問

**Q. 鍵は安全？**
鍵はツールを作る間だけ使い、保存しません。この鍵でできるのはツールを置くことだけで、支払いやパスワードの変更はできません。完成の画面に消し方があります。設置ページの中身は、このページの `setup` フォルダで公開しています。

**Q. 新しい版に更新したい**
設置ページをもう一度はじめから進めてください。データはそのまま残ります。

**Q. ドメインをあとから変えたい**
Cloudflareの管理画面（https://dash.cloudflare.com）の「Workers & Pages」で、「Your subdomain」の横の「Change」を押します。作り直す必要はありません。前のURLは使えなくなるので、メンバーには新しいURLを伝え直してください。変更の直後は「安全に接続できません」と出ることがありますが、しばらく待つと開けます。同じアカウントにほかのサイトがあると、そのURLも変わります。Googleログインを設定したあとに変えた場合は、Googleの設定にも新しいURLを足してください（ツールのログイン画面に手順があります）。

**Q. 要らなくなった。消すには？**
設置ページ（https://team-hub-setup.makikomublog.workers.dev）の「作ったツールを消す」を押して、案内どおりに進めます。**議事録やタスクなどのデータもすべて消え、元に戻せません。** 必要なものは先に控えてください。

Cloudflareの管理画面（https://dash.cloudflare.com）から、次の3つを手で削除することもできます。

- サイト（Workers）：`team-hub`
- データベース（D1）：`team-hub-db`
- ファイル置き場（KV）：`team-hub-files`


**Q. パソコンに詳しいので、自分のパソコンから設置したい**
Macはターミナルで次の1行を実行します（Node.jsなどの部品が約400MB、ホームフォルダの `.team-hub` に入ります）。

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/makikomublog-spec/team-hub/main/install.sh)"
```

WindowsはPowerShellで次の1行を実行します（Windowsでの動作は未確認です）。

```powershell
irm https://raw.githubusercontent.com/makikomublog-spec/team-hub/main/install.ps1 | iex
```

**Q. GitHubのアカウントがあるので、ボタンで設置したい**
こちらのボタンからも設置できます。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/makikomublog-spec/team-hub)

**Q. ログインできなくなった（Googleアカウントを変えた・パスワードを忘れた）**
記録係に頼んで、メンバー画面の「🔑 再設定リンク」を送ってもらってください。
管理者がひとりだけだと困るので、**記録係を2人以上にしておく** のがおすすめです。

**Q. 録音の文字起こしの料金は？**
CloudflareのAIの無料枠（1日あたりの上限あり）で動きます。上限に達すると「本日の無料枠を使い切りました」と出て、文字起こしは翌日から再開します。
無料プランのままなら料金はかかりません。

**Q. 録音した音声はどこに残る？**
音声は保存しません。約20秒ごとにあなたのCloudflareで文字にして、すぐ捨てます。残るのは文字だけです。
録音する前に、会議の参加者に必ず同意をもらってください。

**Q. 録音のやり方は？**
パソコンのGoogle Chromeで「議事録」→「🎙 録音する」。
会議（oVice・Zoom・Google Meet など）はChromeのタブで開き、共有の画面で **そのタブを選んで「タブの音声も共有する」をオン** にします。

**Q. ファイルの容量は？**
合計1GBまで・1ファイル25MBまで（無料の範囲）。8割を超えると画面でお知らせします。

## 自分のパソコンで動かす（作る人向け）

```bash
npm install
npm run dev
```

http://localhost:8791 で開きます（データはパソコンの中だけ。文字起こしは動きません）。
