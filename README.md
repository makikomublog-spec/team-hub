# チーム管理ツール（team-hub）

チームの **タスク・カレンダー・議事録・資料・メンバー** を1つにまとめるWebツールです。
オンライン会議を **録音して自動で文字起こし** し、そのまま議事録にできます。

- あなた専用のサイトとして、**あなたのCloudflareアカウント** に作られます（作った人のデータは、配布した人からは見えません）
- Cloudflareの **無料枠** で動きます
- パソコンでもスマホでも、ブラウザから使えます（録音はパソコンのGoogle Chromeで）

---

## できること

| 画面 | できること |
|---|---|
| まとめ | 目的・方向性、優先タスク、次の節目、最新の決定事項、検討中のこと |
| カレンダー | タスクの期間をバーで表示。ドラッグで日程を変更 |
| タスク | 担当・期限・優先度・完了条件。変更はすぐ保存、履歴も残る |
| 議事録 | 🎙 録音して文字起こし → AIで議事録に整理 → PDFで保存 |
| 情報源 | 要項・資料（PDFなど）を保管。AIで締切やタスクに整理、前の版と比較 |
| メンバー | 自己紹介カード。招待リンクでメンバーを追加 |

## はじめかた

GitHubのアカウントは要りません。**1行コピーして貼り付けるだけ** です。

### 用意するもの（無料）
- **Cloudflareのアカウント** … https://dash.cloudflare.com/sign-up

### 1. 黒い画面を開いて、1行貼り付ける

**Macの場合**

「ターミナル」を開きます（`command` + `スペース` を押して「ターミナル」と入力し、`return`）。
下の1行をコピーして貼り付け、`return` を押します。

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/makikomublog-spec/team-hub/main/install.sh)"
```

**Windowsの場合**

「PowerShell」を開きます（スタートメニューで「PowerShell」と入力して開く）。
下の1行をコピーして貼り付け、`Enter` を押します。

```powershell
irm https://raw.githubusercontent.com/makikomublog-spec/team-hub/main/install.ps1 | iex
```

### 2. ブラウザで許可する

ブラウザにCloudflareの画面が開くので、ログインして **「Allow（許可）」** を押します。
黒い画面に戻ると、自動で続きが進みます。何か質問が出たら、画面の案内に答えてください。

### 3. できたサイトを **すぐに** 開く
黒い画面に `https://team-hub.（あなたのアカウント名）.workers.dev` が表示され、ブラウザでも開きます。**すぐに** 「はじめての設定」を済ませて、このURLをブックマークしてください。
最初に設定した人が管理者になります。

### 4. メンバーを招待する
「メンバー」→「＋ メンバーを追加」→ その人のカードの **「✉️ 招待リンク」** を押します。
出てきたリンクをコピーして、**本人だけに** 送ってください（7日間・1回だけ使えます）。
受け取った人がリンクを開いて、ログインIDとパスワードを決めれば使えるようになります。

## よくある質問

**Q. 黒い画面が怖い。パソコンは大丈夫？**
ツールの部品は、あなたのホームフォルダの `.team-hub` の中にだけ入ります。パソコンの設定は変わりません。設置が終わったら、黒い画面は閉じて大丈夫です。

**Q. 新しい版に更新したい**
同じ1行をもう一度貼り付けてください。データはそのまま残ります。

**Q. GitHubのアカウントがあるので、ボタンで設置したい**
こちらのボタンからも設置できます。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/makikomublog-spec/team-hub)

**Q. パスワードを忘れた**
記録係に頼んで、メンバー画面の「🔑 再設定リンク」を送ってもらってください。
管理者がひとりだけだと困るので、**記録係を2人以上にしておく** のがおすすめです。

**Q. 録音の文字起こしの料金は？**
CloudflareのAIの無料枠（1日あたりの上限あり）で動きます。上限に達すると「本日の無料枠を使い切りました」と出て、文字起こしは翌日から再開します。
無料プランのままなら料金はかかりません。

**Q. 録音した音声はどこに残る？**
音声は保存しません。約20秒ごとにあなたのCloudflareで文字にして、すぐ捨てます。残るのは文字だけです。
録音する前に、会議の参加者に必ず同意をもらってください。

**Q. 録音のやり方は？**
パソコンのGoogle Chromeで「議事録」→「🎙 録音する」。
会議（oVice・Zoom・Google Meet など）はChromeのタブで開き、共有の画面で **そのタブを選んで「タブの音声も共有する」をオン** にします。

**Q. ファイルの容量は？**
合計1GBまで・1ファイル25MBまで（無料の範囲）。8割を超えると画面でお知らせします。

## 自分のパソコンで動かす（作る人向け）

```bash
npm install
npm run dev
```

http://localhost:8791 で開きます（データはパソコンの中だけ。文字起こしは動きません）。
